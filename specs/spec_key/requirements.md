# 错题笔记 - 产品需求文档

> **版本**: 1.0 MVP  
> **更新**: 2025-12-27  
> **核心理念**: 把解题过程变成精美的可保存笔记

---

## 1. 产品定位

### 一句话描述
**拍错题 → AI引导描述 → 生成精美笔记图 → 保存**

### 目标用户
- 初高中学生（12-18岁）
- 有错题整理需求但嫌麻烦的学生
- 想要高效整理学习笔记的学生

### 核心痛点
| 痛点 | 现状 | 我们的解决方案 |
|------|------|----------------|
| 错题本太丑 | 手抄潦草、拍照杂乱 | AI生成精美可视化笔记 |
| 整理费时 | 抄题+写解析要30分钟 | 拍照+AI引导3分钟搞定 |
| 不知道怎么总结 | 不会提炼要点 | AI引导你说出关键点 |

## 2. MVP功能清单

### 2.1 核心流程（唯一流程）

```
┌──────────────────────────────────────────────────────────────────┐
│                                                                  │
│  📸 拍错题  →  🤖 AI引导提问  →  💬 用户回答  →  🎨 生成笔记图  │
│                                                                  │
└──────────────────────────────────────────────────────────────────┘
```

### 2.2 功能详述

#### F1: 拍摄错题
- 用户拍照上传错题图片
- 支持裁剪、旋转基础编辑

#### F2: AI引导式对话 ⭐核心亮点
- AI先识别题目，然后**主动引导用户描述**
- 引导问题示例：
  - "这道题你当时是怎么想的？"
  - "你在哪一步卡住了？"
  - "正确的解法你现在理解了吗？能说说关键点吗？"
  - "下次遇到类似题目，你会怎么做？"
- 用户通过**文字输入**回答（MVP阶段）
- AI根据回答**追问或总结**

#### F3: AI理解与结构化
- 输入：题目图片 + 对话记录
- 处理：
  - 识别题目类型和知识点
  - 从对话中提炼解题思路
  - 分析错因
  - 提炼关键要点和记忆点
- 输出：结构化的解题笔记数据

#### F4: 生成精美笔记图片
- 使用 **Gemini Imagen** 生成
- 图片特点：
  - 📐 清晰的题目展示
  - 📝 结构化的解题步骤
  - 💡 高亮关键知识点（来自用户自己的总结）
  - 🎨 精美的视觉设计
  - 📱 适合手机屏幕比例（9:16）
- 风格选项：
  - 简约学术风
  - 可爱手账风
  - 暗黑极客风

#### F5: 保存
- 保存到个人错题库
- 长按保存到相册

## 3. 用户故事

### 主故事
> 小明做数学卷子时做错了一道函数题。他打开App，拍了这道题。
>
> AI说："我看到这是一道求函数最值的题，你当时是怎么想的？"
> 小明输入："我直接求导了"
>
> AI追问："求导之前需要做什么呢？"
> 小明恍然大悟，输入："哦对，要先看定义域！这道题定义域是x>0"
>
> AI继续："很好！那下次遇到类似题目，第一步应该做什么？"
> 小明输入："先求定义域，再求导"
>
> AI总结生成了一张精美的笔记图片，上面有题目、解题步骤，最醒目的是小明自己总结的要点："**先求定义域，再求导**"
>
> 小明长按保存到相册，感觉这个知识点终于记住了。

### 验收标准
- [ ] 从拍照到生成图片 < 3分钟
- [ ] AI引导问题自然、有针对性
- [ ] 生成的图片包含用户自己的总结要点
- [ ] 图片清晰美观，可保存到相册

## 4. 非功能需求

### 4.1 性能
- 图片生成时间 < 30秒
- 语音转文字实时响应

### 4.2 兼容性
- 移动端优先（H5）
- 支持主流浏览器

### 4.3 数据
- 用户数据本地优先
- 可选云端同步
